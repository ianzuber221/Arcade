# Arcade

Welcome to **Arcade**, an interactive collection of classic arcade games brought to life with modern web technologies.
This Application was part of a coding challenge to make an MVP of a chosen concept in less than 24 hours.

## Features
- A variation of classic gamee the tech industry knows and loves.
- Authentication and persistence
- Track your high scores and challenge your friends.

## Technologies Used
- **JavaScript**: Core logic and game development.
- **React** Front end framework
- **HTML**: Structure and layout.
- **CSS**: Styling and animations.

## Getting Started

### Prerequisites
Make sure you have the following installed:
- A modern web browser (e.g., Chrome, Firefox, Edge).
- [Node.js](https://nodejs.org/) (for local development and running the server).

### Installation
1. Clone the repository:
    ```bash
    git clone https://github.com/ianzuber221/Arcade.git
    cd Arcade
    ```

2. Install dependencies:
    ```bash
    npm install
    ```

3. Start the development server:
    ```bash
    npm start
    ```

4. Open your browser and navigate to:
    ```
    http://localhost:3000
    ```

## How to Play
1. Choose a game from the main menu.
2. Follow the on-screen instructions for each game.
3. Aim for the highest score and have fun!
